VIRO MOBILE — LIGHT UI + SOCIAL FEATURES UPDATE
=================================================

Upload the CONTENTS of this folder into the ROOT of the EXISTING GitHub repo:
https://github.com/piyarabegum1989-rgb/vyro
Replace matching files, commit to main, and use the SAME connected Vercel
project. Do NOT create another Vercel project.

NEW IN THIS UPDATE
------------------
- The mobile social UI now uses a clean white/light background.
- The VIRO V logo is centred on a white PWA/home-screen app icon.
- Tap Followers or Following on a profile to see the actual list of names and
  avatars, like TikTok/Facebook/Instagram.
- Notification page refreshes every 4 seconds. Public follows go to the
  Follows tab. A private account receives a follow REQUEST to accept.
- Messages list refreshes every 3.5 seconds. New messages arrive to the other
  account with unread count, last-message/time and seen status.
- Create -> Add music opens a music picker. It has three original VIRO loops
  (Neon Wave, Night Drive, Sylhet Sun) and public creator-uploaded sounds.

REQUIRED FOR SHARED PRODUCTION DATA
-----------------------------------
Vercel Project -> Settings -> Environment Variables:
DATABASE_URL = your Neon pooled Postgres URL
ADMIN_EMAIL = your own VIRO account email

Vercel Project -> Storage -> Create -> Blob -> connect it to this same project.
That creates BLOB_READ_WRITE_TOKEN. Set it for Production, Preview and
Development and redeploy.

Without Neon, separate accounts cannot share durable follows/messages/posts.
Without Blob, device gallery media cannot be permanently shared. Arena preview
has neither private credential by design; this is why it shows the upload
connection message. Do not send these secret values in chat or commit them.

MUSIC RIGHTS
------------
VIRO Music works like TikTok's select-sound flow, but commercial TikTok songs
cannot legally be shipped without a commercial music licence. Users can use
VIRO starter sounds and their own/public creator sounds now; later connect a
licensed catalog provider for commercial tracks.
