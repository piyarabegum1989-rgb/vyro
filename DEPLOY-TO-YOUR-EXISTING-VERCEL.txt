VIRO MOBILE — FUNCTIONAL UPDATE
================================

Upload the CONTENTS of this folder into the ROOT of the existing GitHub repo:
https://github.com/piyarabegum1989-rgb/vyro
Replace matching files, commit to main, and use the SAME Vercel project. Do
NOT create a new Vercel project.

REQUIRED PRODUCTION SERVICES
----------------------------
1. Vercel Project -> Settings -> Environment Variables:
   DATABASE_URL = your Neon Postgres pooled connection URL
   ADMIN_EMAIL = your own VIRO account email (only this account gets Admin)

2. Vercel Project -> Storage -> Create -> Blob -> Connect to this project.
   This automatically provides BLOB_READ_WRITE_TOKEN.

Save env values for Production, Preview and Development, then redeploy.
Never share or commit the actual token/connection URL.

WHAT THIS UPDATE FIXES
----------------------
- Notification page now refreshes every 4 seconds. Public follows appear under
  Follows; follow requests appear only when the target profile is Private,
  exactly like Instagram.
- Messages inbox refreshes every 3.5 seconds. New messages are visible to the
  other account, with last message, time, unread count and seen status.
- Create post, reel and story works with a caption alone or device media.
  Device media requires the Blob store above for durable shared storage.
- Add music now opens a TikTok-style VIRO Music picker. It includes three
  original VIRO starter loops plus every public original sound uploaded by
  creators. The picker lets a person select a sound for a post/reel/story.
- Profile/cover, post/reel, chat-media and original-audio uploads go directly
  to Vercel Blob with temporary authenticated tokens (up to 100MB).

MUSIC RIGHTS
------------
The UI is TikTok-style, but no app may legally ship arbitrary commercial
TikTok/Instagram songs without commercial music licenses. Add licensed music
provider credentials later to expand the library; creators can immediately
use the included original loops or their own music they have rights to share.

WHY THE ARENA PREVIEW SHOWS A BLOB ERROR
----------------------------------------
The Arena preview intentionally has no DATABASE_URL or BLOB_READ_WRITE_TOKEN,
so it cannot connect to your private Neon/Vercel services. In your existing
Vercel project, adding the two services above enables shared production data.
