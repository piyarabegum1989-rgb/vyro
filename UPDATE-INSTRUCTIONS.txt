VYRO FACEBOOK-CLASS — CLEAN LOGIN + PROFILE + MUSIC + PWA UPDATE
===================================================================

This is an update for the Marketplace / Circles / Trust Score VYRO version
already live at your Vercel link.

WHAT CHANGED
- Removed demo email and password everywhere
- Clean animated VYRO logo on login and create-account screens
- Existing users log in with their email and password
- New users create a new account (name, username, email, password)
- Settings now has gallery selectors for profile picture and cover photo
- Music attachment appears inside Create post
- Install VYRO app works through PWA assets and browser menus

HOW TO UPDATE
1. Extract this ZIP.
2. Open github.com/piyarabegum1989-rgb/vyro
3. Add file -> Upload files.
4. Drag this extracted PUBLIC folder into the GitHub upload area.
5. Replace public/vyro-facebook.html, public/sw.js, public/manifest.webmanifest
   and add the public/icons files.
6. Click Commit changes directly to main.
7. Wait for Vercel to deploy, then hard-refresh (Ctrl+F5) your VYRO link.

MOBILE INSTALL
Android Chrome: three dots -> Install app / Add to Home screen
iPhone Safari: Share -> Add to Home Screen
Windows Edge/Chrome: address-bar install icon or three dots -> Apps -> Install

CURRENT DATA NOTE
This exact Facebook-class interface is still the interactive demo layer:
new demo accounts and files are held in that visitor's browser. A real private
admin menu, shared profile media, gallery uploads for all visitors, and real
messages require the next Neon + Vercel Blob backend conversion of this exact
UI. It should NOT be faked in static HTML, because anyone could bypass it.
