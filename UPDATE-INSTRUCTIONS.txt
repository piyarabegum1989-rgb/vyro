THIS REPLACES THE OLD FEED WITH THE FACEBOOK-CLASS VYRO DEMO
===============================================================

This is the exact VYRO version with:
- Marketplace in Bangladeshi Taka (BDT)
- Groups, Watch/Reels, Messenger, Events, Pages, Memories
- Reactions and per-post audience choices
- Circles with vibe meters (VYRO-only)
- Trust Score Security Center (VYRO-only)

How to update your SAME GitHub repo (piyarabegum1989-rgb/vyro):
1. Extract this ZIP.
2. Open the repo -> Add file -> Upload files.
3. Drag the extracted 'app' folder and 'public' folder into GitHub.
4. Keep/replace same-path files when GitHub asks.
5. Commit changes directly to main.
6. Wait 1-3 minutes for Vercel automatic deployment.
7. Open your normal Vercel domain (do NOT add /feed).

After the update, opening your Vercel link sends visitors directly to the
Facebook-class VYRO interface instead of the old Feed/Reels page.

This exact design is an interactive front-end demo. Reactions, Marketplace,
Groups, Circles and Trust Score work in the visitor's browser. The current
Neon-powered old app remains in the repo, but this demo interface itself is
not yet connected to shared Neon user data.
